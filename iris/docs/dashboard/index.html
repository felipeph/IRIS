Painel de Arquitetura e Regras de Negócio

1. Fluxo de Ingestão e Organização

O ciclo de vida da mídia, desde o cartão SD até a estruturação cronológica no SSD.

graph TD SD((Origem: Cartão SD)) -->|CLI: Ingestão| IN[1_Entrada / Staging] IN -->|Projeto: iris_YYYY-MM-DD| ORG{Motor de Classificação} ORG -->|Fotos Avulsas| AD[2_AlbunsDatas / YYYY / MM / DD] ORG -->|Vídeos Comuns| VD[3_Videos / YYYY / MM / DD] ORG -->|Sequências GoPro| TL[4_Timelapses / Camera / ...] ORG -->|Superzoom/RAW| AST[5_Astrofotografia / Lua / ...] classDef default fill:#ffffff,stroke:#cbd5e1,stroke-width:1px,color:#334155; classDef accent fill:#f1f5f9,stroke:#94a3b8,stroke-width:2px,color:#0f172a,font-weight:600; class IN,ORG accent;
Regras de Ouro:
  • Zero Data Loss: A exclusão da origem requer confirmação e garantia de backup.
  • Naming Convention: `{date}_{time}_{camera}_{focal}_{aperture}_{shutter}_{iso}_{original}.{ext}`

2. Processamento de Vídeo e YouTube

Padrões de renderização e automação de publicação baseados no `timelapse_studio.py`.

graph LR RAW[Clipes Brutos] --> ST[Stitching / Juntar] ST --> FF[FFmpeg Upscale 4K UHD] TSeq[Fotos GoPro] --> FF FF -->|Aceleração GPU| OUT(Vídeo Final .mp4) OUT -->|OAuth 2.0 API| YT{YouTube Upload} YT -->|Resumable Upload| U[Não Listado] YT -->|Metadados Ricos| PL[Auto Playlist] classDef default fill:#ffffff,stroke:#cbd5e1,stroke-width:1px,color:#334155; classDef accent fill:#f1f5f9,stroke:#94a3b8,stroke-width:2px,color:#0f172a,font-weight:600; class FF,YT accent;
Regras de Ouro:
  • Padrão Ouro: Resolução final sempre em 4K UHD (3840x2160).
  • Upload Resumable: Prevenir quebras durante uploads pesados, injetando metadata (GPS, Data).

Mapeamento de funções fora do fluxo quente, rodadas sob demanda pelo usuário.

Regras de Ouro:
  • Deduplicação Rigorosa: O critério de igualdade não usa apenas o nome do arquivo, mas conteúdo (SHA-256).
  • Banco de Dados Local: `folders-2-db` viabiliza navegação off-line estruturada sobre a mídia.
